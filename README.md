# مخبزك

تطبيق أندرويد لحسابات المخبز اليومية والمخزون، يعمل **بدون إنترنت** (Offline-First)، ومبني بـ Flutter وقاعدة SQLite.

> from Abdo Shams

## ما الذي يفعله

- إنتاج اليوم بالقطعيات (عيش كل جوال) والمقارنة بالمفروض.
- الشباك والتوزيع: إيراد الشباك، وحساب كل موزع (المستحق والمسدد والمتبقي).
- المصروفات: ثابتة ومتحركة، ومصروفات الوكيل الشخصية (تُخصم من راتبه آخر الشهر).
- المخزون: الدقيق والخميرة والغاز.
- حساب البنكجي وحساب الوكيل، والتوريدات، وتنبيه فرق البنكجي.
- أيام مقفلة للمراجعة فقط، ولا تُفتح إلا بموافقة الطرفين.

المواصفة المعتمدة في [`docs/spec/`](docs/spec/)، والتصميم في [`docs/design/`](docs/design/).

## الإصدارات

| الإصدار | المحتوى | الحالة |
|---|---|---|
| **1** | تطبيق الوكيل المصغر: مخبز واحد، بدون سحابة، كل البيانات على الهاتف | قيد البناء |
| 2 | السحابة: خادم التفعيل والمزامنة اليدوية (إرسال اليوم / تحديث) | لاحقاً |
| 3 | واجهة المالك: عدة مخابز، وكلاء، استبدال وكيل، قفل الأيام | لاحقاً |

## هيكل المستودع

```
assets/db/schema.sql        مخطط قاعدة البيانات (المصدر الوحيد)
lib/core/accounting.dart    المعادلات المحاسبية (المواصفة §4)
lib/core/labels_ar.dart     نصوص وأرقام العرض بالعربية
lib/core/sql_script.dart    مقسّم سكريبت SQL
lib/core/activation.dart    التحقق من رمز التفعيل (Ed25519، بدون إنترنت)
lib/core/pin_service.dart   رمز PIN (بصمة مملّحة + إيقاف مؤقت بعد 5 محاولات خاطئة)
lib/data/                   فتح القاعدة والمستودعات (الجهاز، الإعدادات، الأيام والقطعيات)
lib/app/                    حالة التطبيق (تفعيل ← بيانات ← PIN ← قفل) وجذر الشاشات
lib/features/               الشاشات (واحدة لكل مجلد)
test/                       اختبارات Dart (أرقام المواصفة نفسها)
tools/verify_schema.py      فحص المخطط على SQLite حقيقية
tools/activation.py         إصدار رموز التفعيل (للمصمم فقط)
tools/verify_activation.py  اختبارات رمز التفعيل
docs/                       المواصفة والتصميم والقرارات المعمارية
.github/workflows/          البناء التلقائي لـ APK
```

## البناء على GitHub (بدون حاسوب)

كل رفع للكود يشغّل البناء تلقائياً:

1. افتح تبويب **Actions** في المستودع، واختر آخر تشغيل لـ **Android**.
2. إذا نجح، نزّل الملف المرفق `makhbazak-debug-apk` من أسفل صفحة التشغيل.
3. فك الضغط وثبّت `app-debug.apk` على الهاتف (يحتاج السماح بالتثبيت من مصدر غير معروف).

الخطوات التفصيلية في [`docs/GITHUB.md`](docs/GITHUB.md).

## التشغيل محلياً (لمن عنده حاسوب)

```bash
flutter create --platforms=android --org com.abdoshams --project-name makhbazak .   # مرة واحدة
git checkout -- lib test pubspec.yaml analysis_options.yaml .gitignore
flutter pub get
flutter analyze
flutter test
python3 -I tools/verify_schema.py
flutter run
```

## قواعد لا تُكسر

كاتب واحد لكل جدول، لا حذف فعلي (الإلغاء بـ `cancelled_at`)، الأيام المقفلة للقراءة فقط، المبالغ أعداد صحيحة. التفاصيل في [`CLAUDE.md`](CLAUDE.md) و[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
